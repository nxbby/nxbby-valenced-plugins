# nxbby's Valenced plugins

Plugins for [Valenced](https://github.com/Valenced/valenced), the Discord mobile client mod.

## Install

1. In Discord, open **Settings > Valenced > Plugins** and tap the gear icon.
2. Add this repository URL:

   ```
   https://nxbby.github.io/nxbby-valenced-plugins/index.json
   ```

3. Tap **+** to browse plugins, install one, enable it, and reload Discord.

## Plugins

| Plugin | Description |
| --- | --- |
| **Femboy** | Adds a `/femboy` slash command that posts a random image from r/femboys. SFW by default, with an optional `nsfw` mode for age-restricted channels. |
